# Play Console Data Safety + Content Rating Answers

Audit date: 2026-05-21. Ground truth is code, manifest, and Play Store copy in this repo only; no web sources were used.

Interpretation used for this draft: ClosePaw has no first-party backend in the audited code, but active cloud tasks transmit prompts, screen observations, tool results, and optional screenshots from the device to the user-selected LLM provider. For Play Console, answer conservatively: screen-derived data is "collected" and "shared" when it is transmitted to that third-party provider during an active task.

## Data collection and security

- [x] **Does your app collect or share any of the required user data types? -> Yes, conditionally.**
  - ClosePaw sends LLM input items and tool definitions to cloud LLM clients; those input items are built from history, memory, app skill text, current screen observation, warnings, and optionally a screenshot. Evidence: `PromptBuilder.buildInputItems()` adds history, memory, app skills, recalled memory, and current observation (`app/src/main/kotlin/ai/closepaw/agent/cognition/prompt/PromptBuilder.kt:40`, `app/src/main/kotlin/ai/closepaw/agent/cognition/prompt/PromptBuilder.kt:48`, `app/src/main/kotlin/ai/closepaw/agent/cognition/prompt/PromptBuilder.kt:53`); cloud clients send those items to OpenAI Responses, Chat Completions/OpenRouter-compatible APIs, or ChatGPT Codex (`app/src/main/kotlin/ai/closepaw/llm/OpenAIResponseClient.kt:255`, `app/src/main/kotlin/ai/closepaw/llm/ChatCompletionClient.kt:279`, `app/src/main/kotlin/ai/closepaw/llm/CodexRequestBuilder.kt:29`).
  - The app stores credentials and local data on device, but the audited code does not show a ClosePaw-operated server receiving user data. LLM routing is to OpenAI API, OpenAI Codex/ChatGPT, OpenRouter, user-configured "Other", or local LFM (`app/src/main/kotlin/ai/closepaw/llm/LLMProvider.kt:25`, `app/src/main/kotlin/ai/closepaw/llm/LLMProvider.kt:32`, `app/src/main/kotlin/ai/closepaw/llm/LLMProvider.kt:39`, `app/src/main/kotlin/ai/closepaw/llm/LLMProvider.kt:46`, `app/src/main/kotlin/ai/closepaw/llm/LLMProvider.kt:59`).
  - User API keys/OAuth tokens are stored in encrypted preferences, not in plaintext prefs. Evidence: `AuthStore` uses `EncryptedSharedPreferences` with `MasterKey` AES-GCM/SIV schemes (`app/src/main/kotlin/ai/closepaw/auth/AuthStore.kt:45`, `app/src/main/kotlin/ai/closepaw/auth/AuthStore.kt:49`, `app/src/main/kotlin/ai/closepaw/auth/AuthStore.kt:53`, `app/src/main/kotlin/ai/closepaw/auth/AuthStore.kt:54`).

- [x] **All data is encrypted in transit? -> Yes for Play release cloud traffic.**
  - OpenAI OAuth/token URLs and Codex runtime URL are HTTPS (`app/src/main/kotlin/ai/closepaw/auth/OpenAIOAuth.kt:19`, `app/src/main/kotlin/ai/closepaw/auth/OpenAIOAuth.kt:20`, `app/src/main/kotlin/ai/closepaw/llm/CodexResponseClient.kt:37`).
  - OpenRouter default base URL is HTTPS (`app/src/main/kotlin/ai/closepaw/llm/LLMProvider.kt:43`).
  - Release builds reject non-HTTPS base URL overrides and disable insecure TLS hooks (`app/src/release/kotlin/ai/closepaw/llm/InsecureSslConfig.kt:7`, `app/src/release/kotlin/ai/closepaw/llm/InsecureSslConfig.kt:18`).

- [x] **Users can request data deletion? -> N/A for server-side ClosePaw data; local deletion exists.**
  - There is no ClosePaw account system/server-side user data in the audited code; cloud providers receive data directly from the app during active tasks.
  - Users can clear provider credentials by signing out or blanking API keys (`app/src/main/kotlin/ai/closepaw/ui/settings/LlmAuthSettingsPage.kt:213`, `app/src/main/kotlin/ai/closepaw/ui/settings/LlmAuthSettingsPage.kt:298`, `app/src/main/kotlin/ai/closepaw/auth/AuthStore.kt:76`, `app/src/main/kotlin/ai/closepaw/auth/AuthStore.kt:168`).

- [ ] **"No tracking, no telemetry" is supported for third-party analytics, but local traces/session logs exist.** The UI warns traces may include screenshots and inputs, and users can clear traces/session history (`doc/release/play-store/full-description.txt:28`, `app/src/main/kotlin/ai/closepaw/ui/settings/PermissionsAdvancedSettingsPage.kt:252`, `app/src/main/kotlin/ai/closepaw/ui/settings/PermissionsAdvancedSettingsPage.kt:278`, `app/src/main/kotlin/ai/closepaw/ui/settings/PermissionsAdvancedSettingsPage.kt:288`).
- [ ] **"API key from OpenAI, OpenRouter, or Novita" is not a first-class provider match.** Code has OpenAI API, OpenAI Codex, OpenRouter, user-configured Other, and Local LFM; Novita appears only as OpenAI-compatible discovery comments, not as a dedicated provider (`doc/release/play-store/full-description.txt:39`, `app/src/main/kotlin/ai/closepaw/llm/LLMProvider.kt:25`, `app/src/main/kotlin/ai/closepaw/llm/LLMProvider.kt:46`, `app/src/main/kotlin/ai/closepaw/llm/ModelDiscovery.kt:102`).
- [ ] **"Microphone not used" would be incorrect if stated anywhere.** The manifest declares `RECORD_AUDIO` and the app uses Android speech recognition for optional voice input (`app/src/main/AndroidManifest.xml:10`, `app/src/main/kotlin/ai/closepaw/ui/capsule/voice/Recognizer.kt:68`).
