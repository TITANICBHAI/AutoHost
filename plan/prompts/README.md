# prompts/
One self-contained kickoff prompt per phase. Paste the phase prompt into the implementing agent's session (or tell it to read the file). Each prompt says what to read, what to build, how to prove it, and what not to do.
Only Phase 0 and Phase 1 are written now; later phases are generated from `_template.md` **after Phase 0** (its results change them). To write one: copy `_template.md`, fill the bracketed parts from `docs/PROGRESS.md` (tasks), `docs/GATES.md` (gates) and `plan.md` §18.
