# AutoHost agent pack
Seed files for the implementing agent. **Unzip into the repository root** (it creates `AGENTS.md`, `plan.md`, `docs/`, `schemas/`, `prompts/`, `samples/`, `tools/`, `sdk-python/`, AIDL under `core/` and `plugin-sdk/`).
Start with `AGENTS.md`, then `docs/PROGRESS.md`, then `prompts/phase-0.md`.
Tracker: tick boxes in `docs/PROGRESS.md`; run `python tools/progress.py` (dashboard) and `python tools/progress.py --check` (rules). `--html docs/progress.html` renders a visual dashboard.
