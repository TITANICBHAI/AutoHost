## 2. Decisions already taken (do not reopen)
Everything from sessions 1–18 stands (ADR-021..078; see `docs/DECISIONS.md`). **Session-19 additions (ADR-079..083):**
- **ADR-079 — plugins contribute capabilities through ONE validated AIDL contract; the host parses and gates EVERYTHING:** the api band, a fail-closed describe() (`plugin.*` ids, one malformed entry rejects the WHOLE plugin), host-collision refusal, typed envelope handling; grants resolve via the immutable `PermissionIndex.mergedWith` (host mappings always win) rebuilt live by `AppGraph.attachPluginPermissions`; discovery rides the `app.autohost.plugin.CAPABILITY_PROVIDER` intent + `<queries>`; `:plugin-sdk` is the dependency-free base, `samples/plugin-example` the F4 vehicle.
- **ADR-080 — app packs ride the RUN CONFIG (`config.packs`):** one mechanism for all three runtimes, version-pinned per run, reserved key (host wins with a logged warning); pack.json v1 fail-closed; named selectors are selector DOCUMENTS rebuilt via the public `autohost.sel.from_json`; missing packs warn at import and at run start — the run proceeds and the SDK's PackMissing makes the failure honest.
- **ADR-081 — the reverse Dev API transport dials OUT; the token rides the FIRST frame, never a URL:** `WsFrames` (pure RFC 6455 both roles, 64-bit lengths, mask-expectation enforced) + `ReverseDevApiLink` (phone = WS client; same dispatch/token/rate-limiter, caller "reverse"); PC `autohost bridge` = WS server + first-frame token validation + a localhost HTTP proxy so existing CLI/MCP tooling works unchanged; the bridge relay is deliberately single-reader (a reader loop racing the relay was the first draft's bug — fixed, do not reintroduce); opt-in per session, gated on the Dev API being enabled.
- **ADR-082 — backups carry secrets as NAMES only; restore re-asks by design:** encode refuses poisoned values, decode refuses `secrets`-class keys anywhere; dev-folder tasks without bundle bytes skip honestly; restore goes through the standard review→install path with source "backup"; profiles re-created with EMPTY secret stores.
- **ADR-083 — the Task Studio edits DEV-FOLDER tasks through the importer's own validator; installed bundles are never hand-edited:** `StudioDraft` overlays edits on the original JSON and validates with ManifestValidator; the repo tab is P11-03's consumer (https/file only, sha-verified install); `StudioController.HOST_API` (currently 8) is the one place that reports the host API level to repo entries.
**Session-15 additions (ADR-064..066):**
- **ADR-064 — the shell tier is our own ADB client, transports behind one seam:** `AdbClient`/`AdbProtocol`/`AdbKeyStore` are pure Kotlin (no AOSP code, no external ADB library); every transport (adb-over-tcp, wireless pairing, Shizuku, root) implements `ShellTransport` and the ordered `ShellTransports` holder picks the first live one.
