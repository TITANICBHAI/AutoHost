# REUSE_MATRIX — what AutoHost takes from the reference projects, file by file

> **Status: PLAN.** Every "Source" below was **read statically** (nothing was built or run — no Gradle, no Android SDK in the planning sandbox). A row is a *decision*, not a claim that code exists or works. Rules: ADR-088 (`docs/DECISIONS.md`); background: `reference/INDEX.md`, `reference/findings/*`; licence ledger: `THIRD_PARTY_NOTICES.md`.
> Roots used below: **CP** = `closepaw-0.1.0/app/src/main/kotlin/ai/closepaw/` · **OD** = `opendroid-main/app/src/main/java/com/opendroid/ai/` · **AA** = `android-agent-main/app/src/main/java/com/foxislam/androidagent/` · **SB** = `sannabotapp-main/` · **AR** = `aria-ai-cpu-only-main/app/src/main/kotlin/com/ariaagent/mobile/` · **AH** = this repository.

## 0. Rules in one screen

**Dispositions** (the brief's five, plus one):

| Disposition | Meaning | May a file be copied? |
|---|---|---|
| **reuse unchanged** | AutoHost's own code stays as it is and is the foundation | n/a (ours) |
| **adapt** | take the file/logic, change it to AutoHost's seams, keep notices | **only** Apache-2.0 files that carry a LICENSE in their own tree (ClosePaw, opendroid) |
| **rewrite** | new implementation of an *idea*, written from the behaviour described in our docs | no |
| **reference only** | read for design lessons; nothing is copied or closely paraphrased | no |
| **defer** | wanted later; gated on a spike or a later phase | no |
| **do not adopt** | deliberately rejected, reason recorded so nobody re-proposes it | no |

**Licence gate.** ClosePaw = Apache-2.0 (`LICENSE` + `NOTICE`, "Copyright 2026 ClosePaw Authors"). opendroid = Apache-2.0 text with one word changed in §4(d) and a header ("OpenDroid Contributors"; the repo is a fork; no `NOTICE`) → treated as Apache-2.0 at low risk, adaptations kept small and file-level. **ARIA** (no LICENSE; owner unverified), **android-agent** (no LICENSE), **sannabotapp** (README says "MIT", no LICENSE file; ships a proprietary Picovoice model) → ideas only, nothing enters a compiled module. Mobilerun Portal (AGPL-3.0) and OpenAutoJs (GPL-3.0 + NC) stay clean-room (`docs/REFERENCES.md` §0). If the ARIA/android-agent/sannabotapp owner grants a licence in writing (a LICENSE file in their tree), rows below can be re-dispositioned by a new ADR.

**What an *adapted* file must carry before its row can close:**
1. a header: `Adapted from <project> <upstream path> (Apache-2.0, <copyright line>). Changes: <what and why>.`;
2. a `THIRD_PARTY_NOTICES.md` row (component, upstream path + version, licence, AutoHost path, "notice preserved") and, for ClosePaw, its attribution line from `NOTICE` (the dependency list in that NOTICE does not apply to us unless we take the dependency);
3. its upstream unit test ported (or replaced by a test that pins the same cases) in the same change;
4. ladder evidence on the tracker task named in the row. **Copying a file is not integration**: the row closes at the evidence level in the "Evidence" column, never earlier. `tools/licence_check.py` is extended by X-11 to fail on an upstream-path header with no notice row.

**Evidence vocabulary** (matches `tools/progress.py`): *JVM* = unit-tested on the JVM (`scripts/test-jvm.sh`); *emulator* = integration-tested on an emulator with the fixture app; *device* = real-device-verified (`device: <model>, Android <n> / API <n>`). Reference-only/defer/do-not-adopt rows need no code evidence; they need the *decision recorded* (this table) and, where a spike gates them, the spike result in `docs/SPIKES.md`.

**Compile/API notes** are from reading build files and sources; compatibility with AutoHost's pinned toolchain (agp 8.13.0, Kotlin 2.2.21, minSdk 29, target 36) is **UNVERIFIED** until a file is compiled in our tree.
