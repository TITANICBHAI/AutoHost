## Lessons
- Read `details.md` on the `ci-results` branch before touching code; fetch with `git fetch -q origin ci-results:refs/remotes/origin/ci-results`. It carries no stack traces and lists failing tests only, so a test timeout is a hypothesis until it passes and "these ran" means the total grew by the number of new tests. **Make a failing UI test name its own step**: wrap every click and wait so the failure message says which one (`at()` in the journey tests), and split a long journey into small tests.
- Run `python3 -m pytest tests` before pushing: the architecture ratchet caught a test that seeds run records (`runStore.create(`); a test-only exception needs a dated entry in `KNOWN`, not a renamed variable.
- Under the JVM test runner a `DropdownMenu` works but an `AlertDialog` with a text box and a lazy list never let Compose go idle (runs 39 and 40; cause not found). Prefer in-page UI for anything a test must drive. Avoid animated progress indicators in screens a test must settle.
- Lazy-list keys must be unique within one list: namespace them by kind (`ListKeys`, `ChatRow.key` = run id + line key). An activity-only smoke test never lays out screens; compose the real screen in a test.
- After adding a variant to an enum or sealed type, grep every `when` over it (CI run 30). Runs 37, 39 and 43 compiled first time because every call site was updated in the same change and imports were checked against the files they come from.
- `performClick` taps a node's centre: scroll the node fully into view first, and keep the test window taller than the page; a tap below the window silently hits nothing (run 40). A disabled button has no click action: look for it by text only.
- `SectionHeader` shows its text in capitals, so a test must wait for "VALUES IT CAN BE GIVEN", not "Values it can be given".
- Most "failures" after compile errors were wrong tests, but four were real product bugs: decide by reading the code.
- A completeness test against the contract caught a missing capability (`device.intent`): generate UI from data, test the join. `ReasonCopy` and `ToolPhrases` follow it (a test compares each with its catalog).
- Missing imports (`dp`, `rememberSaveable`) are the usual first CI failure on Compose files: check imports when writing without a compiler.
- A negative test that greps copy ("no computer") must forbid asking, not mentioning.
- The flow format lives in five places (parser, executor, Python reference, schema, vectors): change them in one commit and regenerate the vectors.
- Keep LF/CRLF as found; use exact find/replace and re-read.
