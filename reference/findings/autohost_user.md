## Static findings in AutoHost code (read-only; NOT run; confidence stated)
1. NodeActions.setText (a11y/Actions.kt:45-53): after ACTION_SET_TEXT it verifies with UiTreeBuilder.safeText(info) == text, i.e. re-reads node.text of the SAME AccessibilityNodeInfo; grep shows NO AccessibilityNodeInfo.refresh() anywhere in non-test Kotlin. A node is a snapshot => verification likely false-negative => provider records REJECTED and falls to IME commit / clipboard paste (possible double entry). conf ~0.85. ClosePaw NodeActionPerformer refreshes before verifying. Unit tests fake UiActions so cannot catch; instrumented G3-g would.
2. ClickOutcome(Route.NODE, verified=true) means only "performAction returned true", not "UI changed". ClosePaw separates accepted / observable change / task correctness and returns verified=false (+warning) when unchanged, and does NOT fall through to another channel on Unchanged (their double-click bug, commit 2042beb).
3. SettlePolicy.fingerprint = index:id:text:desc:bounds only; ignores UiNode.flags (checked/selected/enabled/focused). With click arg retry_if_no_change=true a pure toggle (switch/checkbox) looks "unchanged" and is clicked again (re-toggles). conf ~0.8. ClosePaw fingerprint includes enabled/selected/checked/checkable state, excludes isFocused, adds screenshot pHash when tree empty, 3-step verify 300/500/1000 ms.
4. Gestures fire-and-forget: Gestures.swipe -> service.dispatchGesture(gesture, null, null); returns only "accepted"; no onCompleted/onCancelled, no timeout, no overlay touch gate (AutoHost has its own TYPE_ACCESSIBILITY_OVERLAY bubble/inspector/recorder), fixed 60 ms tap / 600 ms long-press. ClosePaw: awaits callbacks w/ 5 s timeout, tap duration from ViewConfiguration, FLAG_NOT_TOUCHABLE gate + 50 ms settle. Their experiment: dispatchGesture "false success" 0/4 on Files RecyclerView (API 34 emu).
5. scroll_until: swipes from screen centre using screenWidth/screenHeight (defaults 1080x2400 unless wired), not scoped to the scrollable container, never tries ACTION_SCROLL_FORWARD/BACKWARD or directional scroll actions. ClosePaw: a11y scroll first, gesture inside resolved bounds second, never coordinate fallback for scroll.
6. Coordinate fallback = centre of the node bounds (UiTreeBuilder.safeBounds exactCenter) - ClosePaw found container-centre dead zones and promotes to nearest actionable child hotspot (<80% area of the clickable container).
7. SDK Runtime.redact (sdk-python/autohost/_core.py:89): exact-substring replacement of secret VALUES in emitted events; dict KEYS and encoded/transformed secrets are not covered (minor; document the limit).
8. schemas/task.schema.json: runtime.type enum = [python, flow, javascript] (no agent). config_schema and profile_schema both $ref $defs/objectSchema which allows x-secret => a task can declare a secret field inside config_schema; ManifestValidator.kt:258-264 accepts x-secret anywhere. Config is persisted/sent in RunSpec (needs check whether config secrets are routed to SecretStore - UNVERIFIED).
9. core/model RunSpec KDoc "Never contains secrets" but carries runToken (bearer token). RunLimits = timeoutMinutes + idleTimeoutSeconds only (no turn/token/model-call/action budgets).
10. HANDOFF/KICKOFF number mismatch (41 vs 35 tests).
